# Poker Night downloads

Poker Night is a tournament clock and league manager for a home poker league. It runs on Windows 10 and 11, with a TV as a second screen.

## Install it

1. Open the [newest release](https://github.com/sjbelch/poker-night-releases/releases/latest) and download **Poker-Night-Setup** under Assets. It's about 150 MB.
2. Right-click the zip file, choose **Extract All**, then click **Extract**.
3. Open the new folder and follow **START HERE.pdf**. In short: double-click **Install Poker Night**. If Windows says it protected your PC, click **More info**, then **Run anyway**.

## Updates

Once Poker Night is installed, it checks for updates by itself. When one is ready, go to **Settings** and press **Install the update**. Your records stay where they are.

This repository holds only the downloads.
